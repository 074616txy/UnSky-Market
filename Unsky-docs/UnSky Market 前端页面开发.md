## 一、项目背景

这是我的个人项目：**UnSky Market**。

它是一个校园二手交易平台，类似闲鱼，但更偏向校园场景，核心目标是让学生之间的闲置物品重新流动起来。

项目名称 **UnSky Market** 来自我的个人 IP：**Under-Sky-Cloud**。

我的中文名字 / 个人 IP 名称是：

```text
天下云
````


我的英文名字是：

```text
Skyron
```


其中：

- **Under-Sky** 象征“天空之下的广阔世界”；
- **Cloud** 象征“云、流动、自由、连接、记录”；
- **UnSky** 是从 Under-Sky-Cloud 中抽象出来的项目品牌名；
- **Market** 表示交易、流通、校园闲置物品的再次连接。

这个项目不仅是一个后端练习项目，也是我个人 IP 体系的一部分。  
后续我可能会继续扩展这个 IP，比如：

- 设计一个独属于我的动漫风人物形象；
- 设计个人 Logo；
- 设计专属色彩体系；
- 加入云、天空、海浪、船、清晨、航行等象征元素；
- 将 UnSky 系列扩展为我的个人项目品牌。

因此你在设计前端时，不要只把它当作普通校园二手平台，而要把它当作：

```text
一个带有 Skyron / 天下云 个人气质的作品集级产品
```

## 十、权限和 Token 要求

### 1. 普通用户端

- 未登录用户访问收藏、购物车、订单、发布商品时，需要跳转登录页；
- 登录后保存普通用户 token；
- 请求普通用户接口时携带普通用户 token。

### 2. 管理员端

- `/admin` 开头的页面需要管理员登录；
- 管理员登录后保存 admin token；
- 管理员 token 和普通用户 token 分开存储；
- 普通用户 token 不应该用于管理员接口。
